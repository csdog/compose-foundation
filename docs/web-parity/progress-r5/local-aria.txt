Kotlin conventions and accessibility
Kotlin uses a fraction by default: Progress(0.6f) is 60%. The official recipes pass max = 100f explicitly. Use indeterminate = true for unknown progress; ProgressValue then omits the percentage. Compose exposes a normalized progress range and hides the duplicate value text. Native HTML naming, min/null/format/render props and screen-reader behavior are not equivalent APIs.
