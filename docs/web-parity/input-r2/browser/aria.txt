Basic
Field
Use Field, FieldLabel, and FieldDescription to create an input with a label and description.
Field Group
Use FieldGroup to show multiple Field blocks and to build forms.
Disabled
Use the disabled prop to disable the input. To style the disabled state, disable the Field as well.
Invalid
Use the invalid prop to mark the input as invalid. To style the invalid state, mark the Field invalid as well.
File
Use a file picker for file inputs. Compose has no browser-native type="file" control, so this preview approximates the browser field.
Inline
Use Field with orientation = FieldOrientation.Horizontal to create an inline input. Pair it with Button to create a search input with a button.
Grid
Use a grid layout to place multiple inputs side by side.
Required
Use the required attribute to indicate required inputs.
Badge
Use Badge in the label to highlight a recommended field.
Input Group
To add icons, text, or buttons inside an input, use the InputGroup component. See the Input Group component for more examples.
Button Group
To add buttons to an input, use the ButtonGroup component. See the Button Group component for more examples.
Form
A full form example with multiple inputs, a select, and a button.
RTL
To enable RTL support in shadcn/ui, see the RTL configuration guide.
