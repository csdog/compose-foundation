Align
inline-start
Use align="inline-start" to position the addon at the start of the input. This is the default.
inline-end
Use align="inline-end" to position the addon at the end of the input.
block-start
Use align="block-start" to position the addon above the input.
block-end
Use align="block-end" to position the addon below the input.

Custom Input
Add the input-group-control slot to your custom input for automatic focus state handling. The Compose equivalent of the third-party resize-none textarea is the built-in InputGroupTextarea, which grows with explicit rows/minLines instead of a DOM size.

API Reference
InputGroup
The main component that wraps inputs and addons.
InputGroupAddon
Displays icons, text, buttons, or other content alongside inputs. Place it after the input and set align to position it.
InputGroupButton
Displays buttons within input groups.
InputGroupInput / InputGroupTextarea
Replacements for Input / Textarea inside a group; they register the unified input-group focus state. All underlying input/textarea props are passed through.
InputGroupText
Plain text inside an addon (currency, domain suffix, character count).
