- 冷启动深链接、刷新、前进与后退在 JS 和 Wasm 分别验证。双视口检查顺序、页面复制、代码展开、实时更换主题后的弹层颜色和目录跳转。

## 平台与范围

Compose 使用 Canvas 上的可访问语义与定位弹层。可用键盘激活触发器、关闭预览并保留焦点；正文可以选择并复制，Web 端用 Compose 选择状态表示。原生 DOM 选择对象、Base UI Portal 容器 API、任意层数弹层嵌套及屏幕阅读器逐项实测不属于本次组件配方证明。严格的全工作树空白检查会读取既有 Windows Gradle 包装脚本的 CRLF 改动；按 CRLF 规则运行的全工作树检查与本组件范围检查均通过。
