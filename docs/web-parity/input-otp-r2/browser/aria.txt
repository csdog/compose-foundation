Input OTP is built on top of input-otp by @guilherme_rodz. This Kotlin port keeps the same slot composition and paste/backspace behavior with an invisible text field.

Pattern
Use the pattern prop to define a custom pattern for the OTP input.
Separator
Use the InputOTPSeparator component to add a separator between input groups.
Disabled
Use the disabled prop to disable the input.
Controlled
Use the value and onValueChange props to control the input value.
Invalid
Use invalid on the slots to show an error state.
Four Digits
A common pattern for PIN codes. This uses the pattern prop with digits only.
Alphanumeric
Use the alphanumeric pattern to accept both letters and numbers.

InputOTP
Root that owns the value, filtering and paste handling. Slots are visual; one invisible text field captures typing, paste and backspace.
InputOTPSlot / InputOTPGroup / InputOTPSeparator
Slot boxes, connected groups and separators. invalid adds the destructive border and ring to a slot, matching aria-invalid in the official recipe.
