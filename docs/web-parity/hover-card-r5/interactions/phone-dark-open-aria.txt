API Reference
HoverCard
Controlled or uncontrolled root. Provider/root timing aliases remain available for Kotlin callers.
HoverCardTrigger
Use a focusable control in the content slot to support keyboard focus. Trigger timing takes precedence over root/provider aliases.
HoverCardContent
Nova panel uses 256dp width, 10dp padding, an outer ring and 100ms enter/exit transitions.
